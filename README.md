# installation : 

You have to put the .env file inside docker-config/
Then you can make up
```
make up
```
If you want to see all the logs you can 
```
make logs
```
Or (frontend only)
``` 
make logs-react
```
Or (backend only)
``` 
make logs-golang
```

Now you can acces the website / api from : 
```
http://localhost:5130/
```
Or 
```
http://localhost:5130/api/
```
